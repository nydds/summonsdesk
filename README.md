# SummonsDesk

NYC OATH/ECB summons defense desk for Flushing & Queens small businesses.
Static site published with GitHub Pages.

- `/` — English landing page
- `/ko/` — Korean landing page
- `/intake.html`, `/ko/intake.html` — client-side email draft builder (no backend, no data collected)

All figures quoted on the pages were counted from NYC Open Data
"OATH Hearings Division Case Status" (`jz4z-kudi`) on 2026-11-21 for ZIP codes
11354, 11355, 11358, 11360 and 11361.

SummonsDesk is not a law firm. Where OATH rules require representative
registration, it is completed before representation begins.
